# HaoBlog 设计 Skill ——「极夜观测站」可复用设计语言

> 用法：把这份指令当成设计稿生成的种子参数。每次复用时，先在思维里跑一遍"五条设计哲学"，再按"布局模式 / 风格参数 / 动效库 / 交互清单"逐字段产出。不要把这套方案复制粘贴后不做场景化裁剪——每个项目应有不同的"一句话记忆点"。

## 0. 适用场景与硬约束（使用前必读）

适用：技术开发者博客、数字花园、个人知识空间、工具站，目标读者是技术同行。
不适用：电商、SaaS 仪表盘、企业官网、需要日间大量阅读的纯文学博客。

硬约束（继承自 HaoBlog 项目要求，复用时按目标项目调整）：
- 生产环境可能只有 2 核 2GB；重型 3D 库必须路由懒加载、离开页面立即释放。
- 移动端、`prefers-reduced-motion`、`Save-Data` 必须有一等公民降级。
- 文章正文区必须 SSR 可读；首屏不依赖 JS 即可看到标题与正文。
- 不堆砌霓虹、不做玻璃拟态大模糊、不用 Anthropic 暖奶油 #F4F1EA + 陶土橙 #D97757 这一默认配色。
- 颜色对比达 WCAG AA，正文目标 AAA。

## 1. 设计哲学（五条不可妥协的基线）

① **仪器，而非装饰。** 每个发光点、每根轨道线都要承担信息职责；删掉后信息量不变的视觉元素就该被删掉。
② **先安静，再惊喜。** 大部分版面低饱和，把"哇"预算集中在首屏、关键滚动节点、AI/终端展开这几个瞬间。
③ **降级是设计的一部分。** 每个重型效果都要有 SVG 静态回退；首屏动画失败不影响导航与内容。
④ **字就是图形。** 标题字体本身是主视觉；不要用渐变涂色或描边字把字变成霓虹标语。
⑤ **可读性永远赢。** 数字花园、AI 抽屉、终端、可视化是围绕阅读的外层体验，正文区要安静。

## 2. 布局模式（非线性叙事舞台）

**唯一硬骨架**：顶部 1px 磷光发丝线（全站通条，不是 Header）+ 正文舞台（每页一幕）+ 底部 48px 仪表条（Dock）。仪表条上仅 4px 进度条 + 三枚控件：左 = INDEX 径向导航、中 = ⌘K 信号终端、右 = AI 助手。**顶部不出现导航栏**。

**页面模板**：
- 首页：三幕叙事滚动——夜空校准（纯 SSR 零 3D 首屏）→ 星图接入（滚动到此再动态 import Three.js）→ 近期观测日志（SSR 文本）。
- 文章列表：垂直时间线，左侧等宽时间戳，右侧短摘要，hover 点亮标签与关键词。不做三列卡片。
- 文章页：三栏仪器面板——左侧"信号强度"竖条（阅读进度可视化）、中正文 720px、右 TOC 航标。窄屏合并为底部抽屉。
- 知识星图：Canvas + D3 Force，节点用类型字形徽章，连线粗细 = 共现频率；移动端退化为时间线 SVG。
- 工具箱：控制台开关板样式（编号 + 等宽命令名 + 状态灯 + unfold 按钮），点击就地展开内嵌工具。
- 终端 `⌘K`：全站召唤，半透明极夜遮罩 + 克制毛玻璃 `blur(4px)`，白名单命令解析，不连服务器 Shell。
- 404：轻量"丢失信号修复"小游戏，移动端退化为搜索框。

**页面切换**：view-transitions API，旧场景淡出 + 1px 扫描线横扫一次 + 新场景淡入；控制在 250–400ms。

## 3. 风格参数

### 3.1 配色 A · 极夜观测站（默认主题，复用时主推）
- `bg.base = #06110F` 深墨绿黑
- `bg.sub   = #0B1B17` 墨绿炭
- `border   = #1E3A33` 磷光发丝
- `accent  = #A8FF60` 磷光青绿（核心交互、信号灯、进度条）
- `warn    = #FF9D3D` 警示橙（状态、AI 标识）
- `text.mute = #8DB7AC` 雾青（次级铭文）
- `text.main = #E8F1EE` 月光白
- `code.bg    = #0A1A16`
- 对比：accent/base ≥7:1，text/base ≥13:1。

### 3.2 配色 B · 蓝图纸张（日间主题 / 彩蛋切换）
冷纸蓝印，非暖奶油；明显网格 + 硬线条 + 印泥红章做强调。配等宽字体，像 60 年代微波工程图纸。
- `bg = #EDE7DA`、`card = #FFFFFF`、`border = #1F2A3A`、`accent = #2E5C6E`、`stamp = #B7372F`、`text = #16202E`、`mute = #5B6B7A`

### 3.3 配色 C · 信号熔毁（仅彩蛋，30 秒）
- `bg = #0A0000`、`accent = #FF3D2E`、`sub = #FFD23D`、`text = #FFD9D2`

### 3.4 字体
- 标题（拉丁/数字）：**Dagros** 或 **Horizon Type** 800 重；非商用降级 Inter Tight 800。**禁用原版 Inter 当主标题**——会泄露 AI 身份。
- 标题（中文）：得意黑子集化 WOFF2，`font-display: swap`，禁止整字库。
- 正文（中文）：系统字体栈 `"PingFang SC", "HarmonyOS Sans", "Source Han Sans", sans-serif`；阅读模式可挂霞鹜文楷子集。
- 代码：Maple Mono NF CN 必要字符子集。
- 仪器铭文：JetBrains Mono 子集 或 ui-monospace。

### 3.5 图形规则
- 轨道线：`rgba(168,255,96,0.08)` 1px，仅首页星图与文章 TOC 周边。
- 网格：48px 间距、opacity 0.04，移动端关。
- 扫描线：1px `#A8FF60` 上下缓动 6s 周期，`prefers-reduced-motion` 下静态。
- 噪点：SVG `feTurbulence` opacity 0.03，仅首页与星图。
- 节点徽章：方形圆角 8px + 类型字形 + 1.5px 磷光描边。
- 状态灯：4px 圆点，主色 / 警示色。
- **禁用**：大圆角 16px+、玻璃拟态大模糊、霓虹描边、渐变涂色文字、表情图标。

## 4. 动效库选型

- **Framer Motion（主）**：UI 级动效、`layoutId` 共享过渡、抽屉、终端浮卡、径向导航。
- **GSAP（首页按需懒加载）**：编排放大与滚联动，仅首页路由挂载，离开销毁。
- **Three.js（首页星图专属，按需动态 import）**：`import("@/three/HomeScene")`，InstancedMesh + LineSegments 降 draw call，离开 `scene.traverse(dispose)` + renderer.dispose + 移除 canvas；首包外 < 500KB。
- **D3 Force**：知识星图主体与移动端 SVG 版本；只引 `d3-force` + `d3-scale`。
- **CSS-first**：扫描线、呼吸灯、信号竖条优先 `@keyframes`。
- **禁用**：Lottie、全站粒子、视差库在正文区、把所有动画丢给 JS。

## 5. 标志性"哇"交互清单（按需取用，每项都要有降级）

1. **信号锁定首屏**：打字机时间戳 → 标题逐字点亮 → 1px 扫描线横扫。降级：reduced-motion 直接淡入最终态；Save-Data 砍扫描线。
2. **径向导航扇形**：点 INDEX 以光标为圆心展开 5 枚导航点，`scale:0 + rotate:-8deg → 1` 错峰入场，`layoutId` 共享过渡。键盘可达。
3. **滚动驱动星图接入**：IntersectionObserver 触发动态 import Three.js，节点入场 → 连线导通；离开页面 dispose 全部资源。
4. **选区追问光斑**：文章内选中文字即浮"解释/通俗/追问"，layoutId 跟随选区；AI 关闭时退为全文搜索+相关文章，不留空面板。
5. **信号终端 ⌘K**：全局召唤，白名单命令解析，ask 复用 SSE 通道，↑ ↓ 切历史、Ctrl+L 清空、Esc 关闭。
6. **TOC 锚定 + 阅读完成锁定动**：当前章节变"正在观测"，到 95% 时信号竖条一次流光 + "◎ LOCKED"印；`once: true` 不重复。
7. **彩蛋温度**：`theme blueprint` 或 Logo 五连击切蓝图；404 小游戏。主题选择持久化 localStorage。

## 6. 可访问性硬约束

- 所有动效遵守 `prefers-reduced-motion` 与 `Save-Data`。
- 终端、AI 抽屉、音乐播放器：`role="dialog"`、`aria-modal`、`aria-live`。
- SSE 通过 `aria-live="polite"` 克制播报，不逐 Token 刷屏。
- 颜色不作为状态唯一指示，磷光灯点同时配文字标签。
- 四个断点回归：360 / 768 / 1280 / 1600px。
- 触摸设备不依赖 hover。

## 7. 复用工作流

每次接到"设计一个技术博客前端"类请求时，按以下顺序产出：

1. **定哲学**：从五条设计哲学中挑出与该项目最相关的两条作为本稿主线，明确写出。
2. **搭布局**：套用"顶部发丝 + 正文舞台 + 底部仪表条"硬骨架；为该项目的每个页面写一段一幕式描述 + ASCII 草图。
3. **选风格**：从三套配色里选主推，必要时调一两个色值以贴合该项目主题（不要整套换掉，保留"极夜/冷纸蓝图"DNA）。写明字体配对与图形规则。
4. **挑交互**：从七个"哇"清单中挑 3–5 个适合该项目者，逐个写"效果 / 触发 / 情感目的 / 实现思路 / 降级"。
5. **定动效库**：明确哪些库懒加载、在哪个路由挂载、何时销毁，写出资源预算。
6. **A11y 自检**：列一遍降级与可达性清单。
7. **反 AI 脸自检**：刻意写一段"这套设计如何不落入 AI 默认脸"——检查是否避开了暖奶油+陶土橙、深黑+单一酸绿、三列报纸网格这三个默认陷阱之一。

## 8. 一句话记忆点模板

> 把博客前端改写成一台 `[夜间校准信号 / 在工程图纸上勘察 / ...]` 的 `[科学仪器 / 工程台 / ...]`——导航被召唤而来、阅读是一段可被锁定的信号、文章可以当面向你提问。它是 `[极夜的 / 冷纸蓝图的 / ...]`，有轨道、有刻度、有呼吸，但从不霓虹堆砌。

每次复用都要给出针对该项目的"一句话记忆点"，不是把上面这句直接复制。

## 9. 禁止事项（直接命中即重新设计）

- 顶部传统 Header 导航条。
- 三列卡片文章列表 / 九宫格工具卡片。
- 暖奶油底 + 陶土橙强调（Anthropic 默认配色）。
- Inter 作为主标题字面（AI 默认泄露）。
- 全屏粒子或大模糊玻璃拟态。
- 在正文区使用视差破坏阅读锚定。
- 任何降低 Lighthouse 性能 / SEO / A11y 低于 90 的重型首屏动画。

## 10. 与目标实现的协作约定

- 部分 UI 库选用 Reka UI（无样式、可访问性合格）做对话框、菜单、抽屉；不要引入整套 UI 框架污染视觉。
- 主题切换基于 `<html data-theme>` + CSS 变量 cascade；不引第三方主题系统。
- `prefers-reduced-motion` 与 Save-Data 检测放在最早执行的客户端脚本，决定降级路径后再挂载其他模块。
