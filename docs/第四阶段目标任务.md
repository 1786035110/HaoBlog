## 固定验收数据

S4-10 使用独立生产 Compose 项目和临时 PostgreSQL volume，每次重建，测试结束后删除。运行态测试固定建立：

- 一篇开放评论文章和一篇关闭评论文章。
- 待审核、已通过、垃圾、拒绝、一级回复和用户删除评论；测试邮箱、正文、IP 与删除令牌只通过接口验证，不写入日志。
- LINK、SHOWCASE 和五个 `EMBEDDED` 工具：`json-format`、`base64`、`url-codec`、`timestamp`、`regex-test`。
- 分别命中标题、摘要、正文的中文搜索文章，以及一篇未发布、不得公开命中的文章。

## 安全与边界结论

- 运行态 API 日志扫描未发现验收正文、邮箱、IP、删除令牌、评论安全密钥或 SMTP 密码。
- SMTP 故障隔离由 `CommentNotificationMailerTest`、`CommentNotificationOutboxProcessorTest` 和 Outbox 集成覆盖；本地验收未连接真实 SMTP。
- 大文本按字节数限制，正则在独立 Worker 中运行，超时后终止并重建 Worker；主线程不执行正则。
- 生产拓扑仍只有 Caddy、Nuxt、Spring Boot 和 PostgreSQL/pgvector；只有 Caddy 暴露 80/443。
- 未执行真实 SMTP、域名/HTTPS、OSS、部署、远端 CI 或远端生产验收；这些是剩余外部验收项，不是本地 S4-10 通过的推断结果。

## 本轮修复

验收发现 Studio 评论审核列表在 PostgreSQL 下对可选关键词、状态和文章 ID 的参数类型绑定不稳定，并且原生查询会错误追加 Java 属性名 `createdAt`。已将应用层筛选参数明确转为字符串，在 PostgreSQL 查询中显式转换并在 SQL 内处理升降序；未改变 OpenAPI 路径或 DTO 契约。修复后 API 78/78、Failsafe 53/53 和完整 Chromium 14/14 均通过。
