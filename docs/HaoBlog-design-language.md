# HaoBlog 前端设计语言 v1.0 ——「极夜观测站」

> 一句话定位：HaoBlog 不是"又一个技术博客主题"，它是一台**会自己讲故事的观测仪器**。访客走进来，不是在浏览卡片网格，而是在**夜空下校准信号、追踪知识轨迹、与一片有生命力的数字花园对话**。
>
> 这套方案严格服从《HaoBlog 完整开发计划》第 4 章：深墨绿黑底、磷光青绿核心色、低对比网格/轨道线纹理、移动端与低性能设备降级、Three.js 仅首页动态导入。在这个硬约束内，我们要做到第一眼即"哇"。

---

## 1. 设计哲学

设计哲学是五条不可妥协的基线，任何后续取舍都回到这里对齐：

**① 仪器，而非装饰。** 页面里每一个发光点、每一根轨道线，都要承担信息职责。一根扫描线代表"正在接收信号"，节点大小代表关联度，TOC 不是装饰列表而是"观测航标"。如果一个视觉元素删掉后信息量不变，它就该被删掉。这呼应计划里"不为霓虹而霓虹"的取舍。

**② 先安静，再惊喜。** 大部分版面保持低饱和深绿黑底 + 单色青绿；把"哇"的预算集中给 **三秒级首屏、滚动到关键节点、AI 抽屉展开、终端打开**这几个真正需要记忆点的瞬间。克制的反差比全程高亮更高级，也避免移动端 GPU 过载。

**③ 降级是设计的一部分。** 方案默认假定桌面端有 60Hz + GPU；但 `prefers-reduced-motion`、移动端 360px、`Save-Data`、Lighthouse < 90 都会被视为一等公民。每个重型效果都有 SVG 静态回退，首屏动画失败不影响导航与内容。

**④ 字就是图形。** 字体本身就是主视觉的一部分。标题用 Dagros/Horizon/得意黑子集化；行号、刻度、观测时间戳这些"仪器铭文"用等宽字体；不要用渐变涂色或描边字把字变成霓虹标语。

**⑤ 可读性永远赢。** 无论多炫，文章正文区必须留下线宽合适的留白、稳定的行高、可控的对比度。数字花园、AI 抽屉、终端、音乐可视化都是围绕阅读的"外层体验"，正文区是"内核"。外层再炸，内核要安静。

## 2. 布局方案 —— 非线性叙事舞台

打破传统 Header-Sidebar-Content-Footer。核心结构只有三件硬骨架：

1. **顶部 1px 磷光发丝线** —— 全站通条，作为"仪器边框"，不承载导航。
2. **正文舞台** —— 占据视口;每个页面是一个独立"观测场景"。
3. **底部仪表条（Dock, 48px）** —— 替代传统 Header 导航。固定在底部，永远只有三枚控件：左 = 导航索引、中 = 信号终端入口 `⌘K`、右 = AI 助手调取。仪表条上方是 4px 极细进度条，承担"全站阅读进度"，而不是每页各自一个。

导航不出现在页面顶部。访客想跳页时，**左下角索引点开为径向扇形**，像仪器面板旋出；不点开时整个界面几乎没有"导航栏"这种东西。这是第一处记忆点。

### 2.1 全站骨架 ASCII

```
┌─────────────────────────────────────────────────────────────┐
│ ─  顶部 1px 磷光发丝线 · 全站通条（仪器边框，不是 Header）  ─ │
│                                                             │
│                     （正文舞台 / 观测场景）                  chilling
│                        每个页面是一幕                       │
│                                                             │
│                                                             │
│ ─────────────────────────── 4px 全站阅读进度 ──────────────  │
│ [⊙ INDEX]      ⌘K  信号终端         [✦ AI]   ← 48px 仪表条  │
└─────────────────────────────────────────────────────────────┘
        顶部发丝线 + 正文舞台 + 底部仪表条 = 唯三硬骨架
```

### 2.2 首页 —— 叙事性滚动舞台（非对称 Hero）

首页不是"大标题 + 两按钮"，而是一段 **滚动驱动的三幕观测叙事**。我把计划里"左侧个人信号档案 / 右侧交互轨道星图"升级为可滚动推进的舞台，避免首屏即上 Three.js（首屏 SSR 纯静态，3D 第二幕才挂载）。

```
第一幕 · 夜空校准（首屏 · 纯 SSR · 零 3D）

│  观测时间 2026·08·11 03:42 UTC+8                            │
│                                                             │

第二幕 · 星图接入（滚动进入 · Three.js 在此动态导入）
```

### 2.3 文章列表 —— 观测日志时间线（非三列卡片）

拒绝"封面图网格 / 三列卡片"。列表是一条**垂直时间线**，左侧时间戳，右侧短摘要，hover 才"点亮"出该篇的标签与关键词。允许长滚动，因为它讲的是演化，而不是货架。

```
2026·08
  │
  ├─ 08·10 ──────────────────────────────────────
  │        Spring AI 流式 SSE 的三种超时组合
  │        #spring-ai  #sse  #rag       [磷光点亮]
  │
  ├─ 08·02 ──────────────────────────────────────
  │        pgvector 精确检索 vs HNSW 的取舍
  │        #pgvector  #vector             [磷光点亮]
  │
2026·07
  │
  ├─ 07·28 ──────────────────────────────────────
  │        Nuxt 4 混合渲染与后台 CSR 的边界
  │        ...
```

顶部分类 Tab 不做"全部 / Java / Vue"这种平铺标签条，改为**一个滤波器盘**：点击 FILTER，从仪表条上方升起一只圆盘，分类成扇形，选一个再收回。轻、快、好。

### 2.4 文章页 —— 三栏仪器面板（深读写优先）

计划原文是"正文居中、左阅读进度、右 TOC/AI 抽屉"，我保留这个结构骨架，但把两侧做成**仪器面板**而不是侧边栏：左侧是一根"信号强度"竖条（阅读进度可视化），右侧 TOC 是"可点击的航标列表"。窄屏合并为底部控制栏，AI 成为抽屉式覆盖。

```
┌─────────────────────────────────────────────────────────────┐
│  信号     │                                  航标 TOC      │
│  ████░░   │  # Spring AI 流式 SSE            ─── ● 1        │
│  ↑活力度  │  ## 三种超时                        ─── ● 2     │
│           │  ### 连接超时                          ─── ● 3  │
│           │   正文宽 720px                                   │
│           │  "…" 此处为正文                                 │
│           │                                                  │
│           │            〔在文章内选中文字 → 解释/追问〕    │
└─────────────────────────────────────────────────────────────┘
窄屏：左信号条收为顶部 1px 横线，右 TOC 收为底部抽屉
```

### 2.5 知识星图 / 数字花园 —— 可缩放关系画布

计划第 3.5 已规定 Canvas + D3 Force、移动端退化为时间线。我把"节点大小代表关联度、颜色区分类型"再升一级：节点不是圆点，而是**带类型字形的小徽章**（`J` Java / `V` Vue / `A` 架构 / `T` 工具 / `○` 自由节点），连线粗细代表共现频率。双击进入正文，单击弹预览浮卡。

### 2.6 工具箱 —— 设备控制台矩阵

不做"九宫格卡片 + 图标 + 简介"。做成一台**控制台开关板**：每行一个模块 = 编号 + 等宽命令式名称 + 状态灯 + 触发按钮，点击不跳页而是**就地展开内嵌工具 iframe**，像掀开仪器舱盖。

```
┌─ TOOLBOX ──────────────────────────────────────────┐
│  01  json.format        [●ready]     [unfold ▾]     │
│  02  base64.codec        [●ready]     [unfold ▾]     │
│  03  url.codec           [○idle ]     [unfold ▾]     │
│  04  timestamp.conv      [●ready]     [unfold ▾]     │
│  05  regex.sandbox       [○idle ]     [unfold ▾]     │
└────────────────────────────────────────────────────┘
   展开后内嵌工具就地渲染，不跳转新页
```

### 2.7 终端 ⌘K —— 全站召唤，非跳转式

`Ctrl/Cmd+K` 全局唤出，浮于中央，半透明极夜遮罩。终端是白名单命令解析器（计划 3.5.B），不连服务器 Shell。输入框自带等宽 ghost 文字与光标竖条。可 `help`、`ls posts`、`grep "Spring AI"`、`open /posts/...`、`ask "..."` 调 AI、`theme blueprint` 切主题。退出按 `Esc` 或点遮罩。

### 2.8 导航隐藏与呈现的规则总结

- **页面默认看不到导航**。访客有两条路径：左下角 INDEX 径向扇形，或 `⌘K` 终端命令。
- **底部仪表条只展示三枚控件**，不展示整条菜单。这降低了顶部信息密度，让正文真正占据视觉中心。
- **页面切换** 通过 view-transitions API：旧场景淡出 + 1px 扫描线横扫一次 + 新场景淡入，控制在 250–400ms（计划 4.3 约束）。
- **-routing 状态永远可见**：仪表条那 4px 进度条记录全站阅读进度，不是单页的。

## 3. 视觉风格板

### 3.1 配色 A · 极夜观测站（默认主题）

| 角色 | 名称 | Hex | 用途 |
| --- | --- | --- | --- |
| 主背景 | 深墨绿黑 | `#06110F` | 全站底色 |
| 次背景 | 墨绿炭 | `#0B1B17` | 仪表条、卡片、背面层 |
| 边线/发丝 | 磷光发丝 | `#1E3A33` | 1px 边框、分割线 |
| 核心交互 | 磷光青绿 | `#A8FF60` | 活动链接、按钮、进度条、信号灯 |
| 警示/强调 | 警示橙 | `#FF9D3D` | 状态、错误、AI 标识 |
| 正文辅助 | 雾青 | `#8DB7AC` | 次级文字、刻度铭文 |
| 主文字 | 月光白 | `#E8F1EE` | 正文主色 |
| 代码背景 | 编校暗格 | `#0A1A16` | 代码块底 |

对比：磷光青绿对深墨绿黑底 **≥ 7:1**，月光白对深墨绿黑底 **≥ 13:1**，满足 WCAG AAA 文字需求。

### 3.2 配色 B · 蓝图纸张（日间主题，彩蛋切换）

| 角色 | 名称 | Hex | 用途 |
| --- | --- | --- | --- |
| 主背景 | 蓝图纸 | `#F4F1EA` 或更高对比的 `#EDE7DA` | 日间底 |
| 次背景 | 绘图边白 | `#FFFFFF` | 卡片/抽屉 |
| 发丝线 | 绘图墨 | `#1F2A3A` | 1px 边框 |
| 核心交互 | 绘图青墨 | `#2E5C6E` | 链接、按钮 |
| 强调 | 朱印红 | `#B7372F` | 章印式警示 |
| 正文 | 深绘图墨 | `#16202E` | 正文 |
| 铭文 | 退蓝灰 | `#5B6B7A` | 次级铭文 |

调性：蓝图不是"日间奶油风"那种 Anthropic 暖奶油暖陶土，而是**技术绘图的冷纸蓝印**——网格更明显、线条更硬、印泥红章做强调，配等宽字体，像 60 年代微波工程图纸。

### 3.3 配色 C · 信号熔毁（30 秒彩蛋，连续点 Logo 5 次触发）

| 角色 | Hex | 用途 |
| --- | --- | --- |
| 主背景 | `#0A0000` | 暗红熔底 |
| 强交互 | `#FF3D2E` | 熔岩橙红 |
| 副交互 | `#FFD23D` | 警示黄 |
| 文字 | `#FFD9D2` | 烬白 |

仅维持 30 秒，之后自动回到极夜。用于"连续点击 Logo 切换蓝图模式"那个彩蛋链的一环，不常驻、不抢主题。

### 3.4 字体策略（服从计划 4.1 的"禁止整字库"约束）

| 角色 | 选择 | 子集化策略 |
| --- | --- | --- |
| 标题（中文） | 得意黑子集化 WOFF2 | 仅常用 3500 字符 + 所需字重，`font-display: swap` |
| 标题（拉丁/数字） | **Dagros** 或 **Horizon Type** 的 800 重（备 Inter Tight 800，作为非商用降级） | 拉丁字符集仅 26 字母 + 数字，极小 |
| 正文中文 | 系统中文字体栈 `"PingFang SC", "HarmonyOS Sans", "Source Han Sans", sans-serif` | 零下载 |
| 正文中文可选 | 霞鹜文楷子集（仅在阅读模式切换时挂载） | 仅文楷常用字子集 |
| 代码 | **Maple Mono NF CN** 必要字符子集 | 代码字符集极小 |
| 仪器铭文 | 等宽 **JetBrains Mono** 子集 或系统 ui-monospace | 只装数字、拉丁字母、几个符号 |

标题首选 **Dagros / Horizon**（带天文/仪器感的现代字面）而非 Inter——Inter 是当下 AI 默认字面，会泄露身份。得意黑子集做中文部分。这是一处**能被记住的字体选择**，对应计划"标题可使用得意黑"。

### 3.5 图形元素使用规则

- **轨道线**：极淡 `rgba(168,255,96,0.08)` 在背景画 1px 直线或弧线，代表"内容间的隐形联系"，仅出现在首页星图与文章页 TOC 周边。
- **网格**：背景低对比 `linear-gradient` 双向网格，间距 48px，不透明度 0.04；移动端关闭。
- **扫描线**：1px `#A8FF60` 横线上下缓动，周期 6s，`prefers-reduced-motion` 下静态。
- **噪点**：SVG `feTurbulence` 噪点贴层，opacity 0.03，只在首页与星图，文章页关闭以保正文可读。
- **节点徽章**：方形圆角 8px 内填充类型字形，磷光青绿描边 1.5px，背景次背景色。
- **状态灯**：4px 圆点，主色/警示色，用于工具箱与 AI 在线状态。
- **分隔线**：默认 1px `#1E3A33`，章节内用"刻度 + 时间戳"格式，不使用纯装饰横线。
- **禁用项**：大圆角 16px+、玻璃拟态大模糊、霓虹描边、渐变涂色文字、表情符号 Icon。

## 4. 七个让人"哇"的交互细节

> 七个不是堆砌，而是分布在"进入 → 流览 → 深读 → 主动召唤 → 偶遇彩蛋 → 离开与回路"的整条体验线。每处都标注触发时机、情感目的、实现思路，以及对 2GB / 移动端的降级。

### ① 信号锁定首屏（首页第一幕）

**效果**：首屏漆黑；一行观测时间戳以打字机方式出现，随后标题 "HAO" 字母逐字点亮，像夜视仪上校准信号。三秒后一根 1px 磷光线从左向右扫过整个视口，扫描过后标题静止发光，副标题淡入。继续滚动之前，页面上没有任何按钮、导航或卡片。

**触发时机**：首次进入首页。

**情感目的**：用三秒钟的"校准仪式"把访客从橱窗式博客切换到"我在深夜和一台仪器相处"的心境。降低信息密度，让访客愿意向下滚。

**实现思路**：纯 CSS + Framer Motion。SSR 输出静态标题（保证无 JS也能读到），JS 挂载后再用 `motion` 覆盖为序列动画。打字机用 `steps()` CSS 透明度逐字，扫描线用一个绝对定位 div 走 `transform: translateX`。**GSAP 可在首页第二幕才挂载**，让首屏纯 Framer Motion。

**降级**：`prefers-reduced-motion` → 标题直接以最终态出现，只有一次淡入。`Save-Data` / 移动端 360px → 砍掉扫描线，保留淡入即可。

### ② 径向导航扇形（仪表条 INDEX）

**效果**：点 INDEX，以光标位置为圆心展开 5 枚导航点（首页 / 日志 / 花园 / 工具 / 关于），排成半圆，距离 120–160px。选中时该点微微弹起，其他点降低透明度；松手跳页并以 view-transitions 过场。整站顶部永远没有"导航栏"这个东西。

**触发时机**：点击左下角 ⊙ INDEX 控件。

**情感目的**：告别"一条横排导航 = 一个博客"的模板直觉。让访客意识到：导航是**召唤**出来的，不是常驻的。常驻导航带来的眼花被彻底拿掉。

**实现思路**：Reka UI `Menu` 变体。五枚按钮容器叠在 INDEX 控件下方，`scale: 0 + rotate: -8deg → 1` 错峰入场；Framer Motion `layoutId` 让被选中的徽章做"弹起"过渡。用 `pointer-events` + `aria-expanded` 保障键盘可达。

**降级**：低性能跳过 `layoutId` 共享元素过渡，直接做透明度淡入淡出。保证键盘 Tab 顺序仍然可达。

### ③ 滚动驱动的星图接入（首页第二幕）

**效果**：从第一幕进入第二幕，标题下沉，画布展开。一颗颗知识节点从画面外按"距离/类型"顺序入场，连线随后"导通"发亮。滚到底 TimeLine 出现"双击任意节点进入正文"提示。继续滚出第二幕，节点散去淡出，进入第三幕。

**触发时机**：用户滚动到首页第二幕。

**情感目的**：让"知识不是货架，而是一张可触碰的关系网"这个 HaoBlog 核心隐喻被亲眼确认一次。

**实现思路**：**Three.js 按路由懒加载**，在 `IntersectionObserver` 触达第二幕时 `import()`。节点用 `InstancedMesh` 单 draw call 实例化，连线用 `LineSegments` 顶点缓冲，减少 draw call。控制器用 `OrbitControls` 限制俯仰角，禁止平移避免用户找不到回正。**离开首页 `onBeforeRouteLeave` 立即 `scene.traverse(o => o.geometry.dispose())` + renderer.dispose + 移除 canvas**。

**降级**：移动端与 `prefers-reduced-motion` → 用 D3 Force 作静态 SVG（计划 3.5 已允许），同样支持点击。

### ④ 选区追问光斑（文章"问这一段"）

**效果**：在文章区选中一段文字，选区上方浮现一颗 4px 磷光点，然后拉出一道轨道线指向右上浮卡，浮卡里列出"解释代码 / 通俗解释 / 继续追问"三枚按钮。点选后，浮卡扩张为 AI 抽屉的起始气泡，流式答案边出边有标点跳动；首 Token 到达前显示一颗呼吸灯。

**触发时机**：文章正文中用鼠标选中文字或键盘划选（移动端长按）。

**情感目的**：标记这是 HaoBlog 的核心辨识点（计划 3.5.C）——把"阅读"与"向文章提问"合为一个连续手势，不是读者再找一遍按钮。

**实现思路**：`window.getSelection()` + `Range.getBoundingClientRect()`。浮卡位置用 Framer Motion `layoutId` 跟随选区上沿。答案通过 SSE（计划规定 SSE 而非 WebSocket），首 Token 之前用呼吸灯 + `aria-live="polite"` 播报"正在接收信号"。AI 关闭或超额时，浮卡收起为本地"全文搜索 + 相关文章"建议，不出现空面板（计划 3.3 明文要求）。

**降级**：移动端浮卡从顶部套筒下落，不做光斑轨道。

### ⑤ 信号终端 ⌘K 打开

**效果**：全屏出现 1px 边框极夜面板，半透明遮罩 `rgba(0,0,0,0.6) + backdrop-filter: blur(4px)` 一种**克制毛玻璃**，不是流行的大模糊。终端闪动等宽光标，ghost 文字提示 `help · ls posts · grep · open /posts · ask · theme blueprint`。输入命令后结果像 Unix stdout 一样一行行渲染在下方，等宽字体；`ask` 触发 AI 时，结果区域底部出现磷光进度点。

**触发时机**：`Ctrl/Cmd + K` 全局召唤，或点仪表条中间 ⌘K 按钮。

**情感目的**：技术同行在第一秒就笑出来——"这站长把我的博客做成了一台命令行"。同时这是导航之外的**第二条导航路径**，以及"跳页 / 搜索 / 调主题 / 调 AI"的统一入口，把几个功能压到一个面板里，是对页面装饰物的一次大清理。

**实现思路**：Reka UI `Dialog` +Trap Focus + `aria-modal`。命令解析器是一个 60 行的白名单 Parser，对应计划 3.5.B。`ask` 命令直接复用 SSE 通道。终绗历史用 `↑ ↓` 切换，`Ctrl+L` 清空，`Esc` 关闭。

**降级**：`backdrop-filter` 不支持（旧浏览器）→ 纯色 92% 不透明遮罩。

### ⑥ TOC 单击锚定 + 阅读完成"锁定"动效

**效果**：文章右侧 TOC 不是简单高亮当前章节，而是把当前章节节点变成"正在观测"状态——节点颜色由雾青变为磷光青绿，相伴左侧信号竖条点亮到当前进度。滚动到文章末尾的瞬间，**信号竖条整道亮起一次并从上到下轻轻流过**，TOC 列表最后一项旁边出现一枚极小的"◎ LOCKED"字样，表明"这段信号已锁定"，克制的胜利感。

**触发时机**：滚动进入每个标题；滚动超过 95% 文章长度。

**情感目的**：让"读完一篇文章"成为一件有仪式的小事。HaoBlog 的读者是技术同行，读到底值得被纪念一瞬，而不是默默消失。

**实现思路**：`IntersectionObserver` 监听所有 `h2/h3` 的可见性，更新 Pinia 中的当前锚 ID。信号竖条是一个 `height` 缓动到 `scrollProgress%` 的 2px 元素。最后 95% 用一次性 `motion` 触发锁定动画，`once: true` 不重复。

**降级**：`prefers-reduced-motion` → 竖条直接到位，不流光。

### ⑦ 彩蛋温度：蓝图切换 / Logo 五连击 / 404 游戏中心

**效果**：

- **蓝图切换**：`theme blueprint` 命令或连续点击 Logo 5 次，整站以 view-transitions API 切换到配色 B 蓝图纸张，文字形体保持，但视觉像被一张工程图覆盖，背景出现更明显的网格。
- **404 游戏中心**：404 页面保留搜索与返回路径，并按用户操作懒加载贪吃蛇、2048、扫雷三个独立小游戏；游戏内容不承担主题叙事，也不保存成绩。
- **阅读完成锁定动**：见 ⑥。

**触发时机**：用户主动探索或在错误路径上。

**情感目的**：技术同行吃这一套。彩蛋要"藏得起来"，发现时的归属感远高于装饰。

**实现思路**：主题切换基于 `<html data-theme="...">` + CSS 变量 cascade，主题选择持久化在 localStorage（计划允许 localStorage 在访客端使用， werktuig 仅禁止 SSR 时持久化）。404 游戏中心及单个游戏分别按交互懒加载，不拉 Three.js。

**降级**：无 JavaScript 时只显示搜索与恢复链接；移动端使用触屏方向键，Save-Data 不会自动加载游戏代码。

## 5. 动效与库选型（对齐 2GB 与性能预算）

- **Framer Motion（S那优先）**：处理 UI 级动效（淡入、layoutId 共享过渡、抽屉、终绗浮卡、径向导航）。10KB 左右，已含 Vue 生态兼容方案。
- **GSAP（按需懒加载）**：用于首页第二幕的编排放大与滚联动，仅在首页路由挂载，离开即销。
- **Three.js（首页星图专属）**：按计划"不在文章主包"分到独立 chunk。**`import("@/three/HomeScene")`** 从首页第二幕触发，抓取的压缩资源 < 500KB（首包外）。
- **D3 Force**：知识星图主体与移动端静态 SVG 版本共用；不上整 d3 包，只引入 `d3-force` 与 `d3-scale`，控制在 30KB 左右。
- **CSS-first**：扫描线、呼吸灯、信号竖条进度优先用 `@keyframes`，不笼统地把一切丢给 JS 动画。

绝不使用：
- Lottie（大且难懒加载）。
- 全站粒子（计划要求克制霓虹化）。
- 视差库（如 Rellax）在文章正文区—— 会破坏阅读稳定的锚定感，视差保留给首页第二幕叙事。

## 6. 可访问性硬约束（服从计划 4.4）

- 所有动效遵守 `prefers-reduced-motion` 与 `Save-Data`。
- 终端、AI 抽屉、音乐播放器提供正确 ARIA 语义（`role="dialog"`、`aria-modal`、`aria-live`）。
- SSE 流输出通过 `aria-live="polite"` **克测播报**，不逐 Token 刷屏（计划 4.4 明文）。
- 颜色不作为状态唯一指示，磷光灯点同时配文字标签。
- 在 360 / 768 / 1280 / 1600px 四个断点回归测试，触摸设备不依赖 `hover`。

## 7. 这套设计如何不成为"AI 默认脸"

刻意回避三处陷阱：**(A)** 不用 Anthropic 暖奶油 #F4F1EA + 陶土橙 #D97757 ——我们的日间主题是**冷纸蓝图**而不是暖纸奶油；**(B)** 不用"深黑 + 单一酸绿"这一爆款默认 ——极夜底用了带绿调的 #06110F、磷光青绿 #A8FF60 仅在三处关键交互亮起，其他时候背景维持深深墨绿黑；**(C)** 不做手机版三列卡片观测列表 ——整站列表是仪器时间线。把"不让别人秒认出是 AI 产出"当做一次设计自我审查。
