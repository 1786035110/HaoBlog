# 阶段三准入清单：公开阅读

阶段三只处理公开阅读体验，不提前实现评论、工具箱、AI、RAG 或阶段四以后功能。

## 当前基线

- 阶段二远端 CI 已通过：API、Web、OpenAPI、Compose、PostgreSQL、生产拓扑和 Chromium E2E。
- 公共首页、文章列表、文章详情和无 JavaScript SSR 已有基础实现。
- 文章详情已有基础 SEO Meta 和安全 Markdown 渲染。
- 媒体存储适配器已切换为阿里云 OSS；未配置真实 AccessKey 时只运行离线签名和集成测试。
- 当前未完成：文章 TOC、Shiki 代码高亮、Canonical/JSON-LD 完整输出、RSS、Sitemap 和公开阅读性能验收。

## 开发顺序

### S3-01 公开数据与页面基线

- [ ] 校验 `/api/v1/public/site`、文章列表和文章详情 DTO 的缓存头、ETag 和分页边界。
- [ ] 首页展示站点信息和最近公开文章入口。
- [ ] 列表页展示发布时间、摘要、封面和空状态。
- [ ] 文章页以不可变发布快照为数据源。

### S3-02 文章阅读结构

- [ ] 从安全 Markdown 渲染结果生成稳定的 h2/h3 TOC。
- [ ] TOC 锚点对重复标题稳定去重，并支持键盘导航。
- [ ] 代码块按需接入 Shiki；不把高亮运行时代码放进首屏必需路径。
- [ ] 保持无 JavaScript 时正文、标题和 Meta 可见。

### S3-03 SEO 与订阅入口

- [ ] 输出 title、description、Canonical、Open Graph 和 Twitter Meta。
- [ ] 输出文章 JSON-LD，正文内容不得依赖客户端执行后才出现。
- [ ] 增加 `/rss.xml` 和 `/sitemap.xml`，只包含已发布文章和站点公开页面。
- [ ] 处理 slug、分页、404、草稿和预览链接的索引边界。

### S3-04 响应式与性能验收

- [ ] 验证 360px、移动端和桌面端阅读布局。
- [ ] 验证 `prefers-reduced-motion`、Save-Data 和无 JavaScript 路径。
- [ ] 文章首屏不加载 Three.js、编辑器或其他重型交互依赖。
- [ ] 使用 Playwright 验证 SSR HTML、Meta、TOC、RSS、Sitemap 和文章图片。

## 阶段三验收命令

```powershell
corepack pnpm install --frozen-lockfile
corepack pnpm --dir apps/web typecheck
corepack pnpm --dir apps/web test
corepack pnpm --dir apps/web build
corepack pnpm --filter @haoblog/api-client check
```

API 变更另行运行 Java 21 Maven 单元测试和 PostgreSQL 集成测试。真实 OSS 上传、域名 HTTPS 和备案状态在阿里云配置完成后单独验收，不用占位凭据冒充通过。

## 阶段边界

- 评论、审核、限频：阶段四。
- 工具箱：阶段四。
- 百炼 Chat、Embedding、SSE、RAG：阶段五及以后。
- 备案、真实域名 HTTPS、ACR 和自动部署：域名备案完成后执行部署阶段验收。
